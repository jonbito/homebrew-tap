# Homebrew Tap for CLI Projects

This is the official Homebrew tap for the following CLI tools:

- [LazyJira](https://github.com/jonbito/lazyjira), a terminal-based JIRA TUI application.

## Installation

```bash
brew tap jonbito/tap
brew install lazyjira
```

Or install directly:

```bash
brew install jonbito/tap/lazyjira
```

## Updating

```bash
brew update
brew upgrade lazyjira
```
